# Human-powered glider sound masters

The user plans to create these files later. No flight sound masters have been
supplied and no flight sound import/playback pipeline is implemented yet.

See the [Japanese production brief](../../../docs/FLY_AUDIO.ja.md).

Core files: `wind-soft.wav`, `wind-fast.wav`, `pedal-drive.wav`,
`ground-roll.wav`, `touchdown.wav`. Optional: `stall-buffet.wav`.

Place originals here. Audio and editing sidecars stay outside Git; only this
README is tracked. Preserve masters unchanged and create derived imports under
the app's ignored artifacts/ and UE Content/ directories. Their redistribution
rights must be recorded when supplied; the code's MIT license does not cover them.
