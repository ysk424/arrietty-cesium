# 効果音

2026-09-11 に用意された Adobe Firefly 正式版の5素材を使用します。

| 素材 | 再生タイミング |
|---|---|
| `catch.wav` | 通常運動中、既存のモデルが一漕ぎを認識したときに1回。重複再生なし |
| `pull.wav` | 引く動作の強さに合わせて音量を変え、戻す動作では短くフェード |
| `boat.wav` | 船速に合わせて音量とピッチが変化。惰性で進んでいる間も鳴る |
| `silent-water.wav` | 静かな水面のループ。走行中は少し控えめになる |
| `silent-wind.wav` | 静かな風のループ |

待機・キャリブレーション・一時停止・停止・追跡喪失中は水面と風だけです。
運動の音は80 msで消音します。キャリブレーションの2ストロークでは入水音を鳴らさず、
音響処理は距離・時間・漕ぎ数・操舵に書き込みません。
入水の判定は既存の漕ぎ数判定と共通で、引き始めから約8 cm移動した時点です。

左は右より **6 dB** 大きくしています。元素材を一度モノラルにまとめ、
両耳に同じ音を送り、右を左の約0.5012倍にします。これにより素材固有の左右差や
頭の向きで補正量が変わりません。現在は方向による定位を付けていません。
元のWAV自体は変更せず、加工後のステレオPCMをUEに取り込みます。
継続音には末尾と先頭のクロスフェード、入水音には短い開始・終了フェードを加えます。

5音が最大値で同時に鳴っても、計算上のピークはマスター音量1で0.755以下です。
初期音量は0.8。通常は次のように起動できます。

```powershell
./run.ps1 "Koh Hong"
./run.ps1 "Koh Hong" -Volume 0.5
./run.ps1 "Koh Hong" -Demo -Volume 0.5
./run.ps1 "Koh Hong" -Volume 0
```

`Volume` は0〜1で、0は消音です。左右の6 dB差は全体音量を変えても維持します。
OS・ヘッドホン側の音量や左右設定は変更しません。

素材を入れ直す場合は `sounds/` に上記5ファイルを置いて
`./tools/prepare_audio.ps1` を実行します。これは音声アセットだけを更新します。
通常の `prepare.ps1` にも音声準備を含めています。生成物はGit対象外です。

追加音は必須ではありません。将来足すなら「オールを水から抜く音」が候補です。
開始・一時停止の短い確認音も追加可能ですが、今回の5素材には含めていません。

開発時は `./tools/build_native.ps1` と `./tools/test_audio.ps1` で検証します。
後者は機器を接続しないUEデモを起動し、ゲームの出力だけを30秒録音します。
マイク録音は行いません。ログ・WAV・測定結果は無視対象の `logs/`、`artifacts/audio/`
およびUEの `Saved/AudioCapture/` に保存します。ヘッドホンでの聞こえ方や
長時間の快適さは、出力データの検査だけでは判断できません。

UEの仕組みは Epic の [AudioComponent](https://dev.epicgames.com/documentation/en-us/unreal-engine/API/Runtime/Engine/UAudioComponent)
と [音声の取り込み](https://dev.epicgames.com/documentation/en-us/unreal-engine/importing-audio-files)
を参照しています。
