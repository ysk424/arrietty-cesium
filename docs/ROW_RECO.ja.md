# おすすめの水面31か所

`reco.json` は世界の海・湖を31か所選んだカタログです。
`reco.ps1` が番号を場所名・半径・速度倍率へ変換して、既存の `row.ps1` を呼びます。

```powershell
./reco.ps1              # コメント付きの一覧を表示し、番号を入力
./reco.ps1 14           # 14番の中禅寺湖。コメントを表示して通常のROWへ
./reco.ps1 -List        # 一覧だけ表示。通信・場所検索・UE起動なし
./reco.ps1 31 -Show     # 31番の説明・設定・出典だけ表示。通信なし
./reco.ps1 1 -Demo      # 実機を使わない通常のデモ起動（地形には通信を使う）
```

番号選択後の場所検索、水面の選定、水位確認、Yによる起動確認は通常のROWと同じです。
`row.ps1` 自体には番号の意味を追加していません。番号指定は `reco.ps1` に渡してください。
番号選択時の空入力・入力終了は終了します。場所確認のN・空入力・入力終了でも起動しません。
未選択の30か所の検索や準備は行いません。全地点を先読みする機能はありません。

## 範囲と速度

「範囲」は**出発点を中心とした半径（km）**です。直径や湖の大きさではありません。
倍率は、等倍で10 km/hの漕ぎ方を10分続けたときの直進距離が半径になる値です。

`速度倍率 = 半径km ÷ (10 km/h × 10/60時間) = 半径km × 0.6`

例えば半径5 kmでは3倍、地形上の速度は約30 km/hです。
カタログは半径2～6 km・倍率1.2～3.6倍で、既存ROWの許容範囲内です。
半径は景観を巡るための設定案であり、現地水面の寸法の測定値ではありません。
10分は障害物のない直進での計算です。島・岸・曲がり道、漕ぐ速度によって実際の時間は変わります。
ブレッド湖やモレーン湖など小さな湖では、範囲の円に達するより先に湖岸があります。
倍率によって旋回半径も広くなるので、岸へ近づく前に方向を変えます。

## 情報と通信

- 各項目には番号、日本語名、国、海/湖、検索用の場所名、半径、倍率、コメント、出典URLを収録。
- 景観情報は観光局・国立公園・UNESCO等の公開資料を確認し、短いコメントにまとめました。
  各項目の `sources` が出典、`reviewed_on` が調査日です。
- 座標や湖面標高の固定値は入れていません。選んだ1か所だけ、通常のROWの場所検索と
  ローカルキャッシュを使います。検索APIの設定・通信は通常起動と同じです。
- 一覧と `-Show` はローカルJSONを読むだけです。起動確認でYを入力した後は、選択地点の
  通常の地理準備・Cesium地形/画像の読み込みが発生します。
- このカタログの作成・テストではCesiumの地形・画像を取得していません。
  31地点の起動・描画品質・湖面位置を実測確認したカタログではありません。
- 不明な湖面標高を海抜0や湖底で代用しません。確認できない地点では通常のROWと同じく
  準備を止めます。確認済み水位を指定する場合は `-WaterLevelM` を使えます。
- 現地の水色・透明度・滝・建物・植物を追加する設定ではありません。表示は既存ROWと
  Waterline、Cesiumで利用可能なデータに依存します。細い水路の通過も保証しません。

`-Demo`、`-LegacyWater`、`-RefreshPlace`、`-Volume`、`-WaterLevelM`、`-Model`、
`-EngineRoot` を通常のROWへ転送できます。半径・倍率は選んだ項目の値を使います。
これらを別に試す場合は通常の `row.ps1 "場所" -RadiusKm ... -Mag ...` を使用してください。

## 検証

`./tools/test_reco.ps1` は一時フォルダーのスタブ起動スクリプトを使用します。
31件の選択と倍率計算、引数転送、一覧・説明・キャンセル、不正データの拒否、
起動エラーの伝播を確認します。実際のROW、Cesium、検索API、機器には接続しません。
PowerShell 7.6.3とWindows PowerShell 5.1でそれぞれ112チェックに成功しました。
