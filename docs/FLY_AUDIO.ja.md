# 人力グライダーの音：制作仕様

まずは**基本5種類**を用意してください。任意の失速音を加えると6種類です。
最初に飛行中の感触を作るなら、優先度の高い風2種類と駆動音の3種類から始められます。
これは次回の音声実装に向けた制作案です。flyの音素材は未受領で、再生処理も未実装です。

## 制作する素材

| ファイル名 | 内容 | 長さ・再生 | チャンネル |
|---|---|---|---|
| `wind-soft.wav` | 穏やかに空気を切る、滑らかな風音。低速滑空の基礎 | 15～30秒・ループ | ステレオ |
| `wind-fast.wav` | 空気の流れが強くなった風音。滑降・速度感のための追加層 | 15～30秒・ループ | ステレオ |
| `pedal-drive.wav` | ペダルから伝達機構へ伝わる、軽いチェーン・軸受けの回転音 | 8～15秒・ループ | モノラル |
| `ground-roll.wav` | 軽い機体の小さな車輪が滑走路を転がる音 | 8～15秒・ループ | モノラル |
| `touchdown.wav` | 軽い接地の「コトッ」と短い振動。余韻まで含む | 1～2秒・単発 | モノラル |
| `stall-buffet.wav`（任意） | 失速に気づくための演出用の軽い空気の乱れ・ばたつき | 3～5秒・ループ | モノラル |

人力グライダーの静かな飛行が中心です。エンジン音やジェットの轟音は不要です。
駆動音は一定のテンポで作り、ペダル回転数に合わせた変化はアプリ側で付けます。
風2種類は音色と空間の広がりを近づけ、弱い音から強い音へ混ぜても自然になる組にしてください。
離陸の専用音は作らず、車輪音が消えて風音が残る移行で表現します。

## 書き出しと音作り

- 推奨納品形式：**WAV / PCM 16bit / 48kHz**。音ごとに別ファイルにします。
- ループは音量と音色をなるべく一定にし、終端と先頭がつながるようにします。
  ループ素材へのフェードイン・アウト、長い無音は付けません。
- 飛行の開始・終了、音量・速度変化のフェードはアプリ側で行います。
- BGM、声、鳥、地上の環境音、長い残響は混ぜず、個別の素材にします。
- マイクへ直接風を当てたような低音の破裂、耳に刺さる高音、強い左右の往復を避けます。
- クリッピングを避け、書き出しのピークに約3～6dBの余裕を残すのを目安にします。
  5素材をすべて最大音量へ揃える必要はありません。
- 24bitなどの高品質な制作元があれば、その元データも手元に残してください。
  上記16bit WAVを受け渡し用にします。UEも16bitでのインポートを推奨しています。
  [Epic公式：Importing Audio Files](https://dev.epicgames.com/documentation/unreal-engine/importing-audio-files)

保存先はリポジトリ内の`apps/fly/sounds/`です。音素材・編集用ファイルはGit対象外です。
元ファイルは変更せず、必要な加工・ループ調整・UE用データは別の生成先で作ります。

## 素材を受け取った後の組み込み方針

1. 風は飛行計算上の対気速度に合わせて2層を混ぜます。`WORLD`速度は必要に応じた
   演出補正として扱い、`-mag 10`で音量や再生ピッチを10倍にはしません。
2. 駆動音は漕いでいる間に鳴らし、漕ぐのをやめると静かに減衰させます。
   **滑空中は風音が続きます。**
3. 車輪音は接地中の移動にだけ連動させ、空中では消します。
4. 接地音は着地の瞬間に1回鳴らします。任意の失速音は失速中に弱く重ねます。
   接地音・ばたつきの変化で足りるかは実際に聴いて決めます。
5. 一時停止・地形待ち・追跡喪失・終了時の音も確認します。機器の負荷やファン制御は変更しません。

素材受領後に、オフラインの録音確認と実機HMDでの試聴を行います。
