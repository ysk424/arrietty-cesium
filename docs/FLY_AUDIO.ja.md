# 人力グライダーの音

2026-09-12に提供された**6種類**をflyへ組み込みました。
基本5種類に、追加された足踏みプロペラ音を独立した音として加えています。
任意だった失速のばたつき音は未提供・未実装です。現在の6種類で飛行できます。

同日、ユーザーから `fly.ps1` で音が正常に再生されたとの確認を得ました。
自動録音テストとは別の実機試聴による確認です。各場面の個別評価や長時間の快適さは未記録です。

## 素材と動作

| 正式なファイル名 | 今回の`wav_fly/`のファイル名 | 再生 |
|---|---|---|
| `wind-soft.wav` | `wind-soft.wav .wav` | 穏やかな風。滑空中も対気速度に連動 |
| `wind-fast.wav` | `wind-fast.wav.wav` | 20km/hを超えると混ざり始める強い風 |
| `pedal-drive.wav` | `pedal-drive.wav.wav` | ペダル・伝達機構。回転数で音量とピッチ、出力で音量を補正 |
| `propeller.wav` | `propeller.wav` | 足踏みプロペラ。同じ回転数・出力で変化し、駆動音よりゆっくり減衰 |
| `ground-roll.wav` | `ground-roll.wav.wav` | 地上走行速度に連動。空中では消える |
| `touchdown.wav` | `touchdown.wav` | 飛行から着地した瞬間に1回。衝突停止・復帰では鳴らさない |

提供素材はすべて48kHz・PCM16・ステレオで、ループ5種類は各15秒、接地音は1秒です。
ファイル名の重複拡張子・空白にも対応しました。元ファイル名と内容は維持します。

**漕ぐのをやめても、滑空している間は風音が続きます。**
ペダルとプロペラは回転数がゼロになると減衰します。機器情報が1.25秒以上更新されない場合も
駆動音を消します。プロペラの減衰時定数は0.4秒で、停止後も短く余韻が残ります。
風は飛行計算上の対気速度（`AIR`）に合わせます。`-mag 10`でも音量・ピッチは10倍になりません。
実機の負荷・ファン制御・飛行計算は従来通りです。
初期設定、Button 1整列前、地形待ち、接触停止、追跡喪失、Esc停止では音を消します。
ブリッジの通信が1秒途絶えた場合も減衰します。

## 使い方

```powershell
./fly.ps1 "富士山" -StartMode Air -StartAglM 100 -mag 10 -Volume 0.8
```

`-Volume`は0～1、標準0.8です。0で消音、1で最大です。
UEの再生出力を使用し、マイクは使用しません。HMDでの最終的な聞こえ方・音量は実機試聴で調整します。

## 素材を更新する場合

1. 元素材を`wav_fly/`に置きます。上表の正式名または今回の納品名に対応します。
   別環境では正式名で`apps/fly/sounds/`に置いても構いません。こちらが優先されます。
2. fly/Unreal Editorを終了して、次を実行します。

```powershell
./apps/fly/tools/prepare_audio.ps1
./apps/fly/tools/test_audio.ps1
```

通常の`./tools/prepare.ps1 -App Fly`でも素材があれば取り込みます。
新規環境で元素材が一切ない場合は音なしで準備でき、一部だけある場合は不足を報告します。
ソースコードだけを取得しても音素材は配布されません。

ループ素材は再生用のコピーでDC成分を除き、末尾と先頭の0.2秒を重ねてつなぎます。
生成ループは14.8秒です。風はステレオを維持し、機械・車輪・接地音はモノラルにまとめます。
左右共通のゲインでピークを0.5以下に揃え、ミックス時の余裕を残します。
row専用の左耳+6dB補正はflyには適用していません。頭を振っても音が左右へ移動しない再生です。
UEへはPCM・事前読み込みで取り込みます。

元素材は変更せず、派生WAVとハッシュ記録は`apps/fly/artifacts/audio/`、UE資産は
`apps/fly/unreal/ArriettyUE/Content/Fly/Audio/`に生成します。
`wav_fly/`内の制作元フォルダーも含め、元素材・生成物はすべてGit対象外です。
提供音素材をコードのMITライセンスとして再配布する許諾は扱っていません。

## 確認方法

`test_audio.ps1`は空のマップに専用の模擬入力を与え、UEの出力を30秒録音します。
準備中→地上で漕行→動力飛行→無動力滑空→高速滑空→着地・地上走行→停止を確認します。
音素材・ループ設定・接地回数、無音区間と有音区間、高速風の増加、クリッピングの余裕を検査します。
機器・マイク・SteamVR・Cesium配信は使いません。録音は`apps/fly/artifacts/audio/ue-mix-*.wav`です。

実機では漕ぐ／やめる操作、機首を下げた滑空、地上からの離陸・着地、Esc停止を聴いてください。
自動検証は実機HMDでの音量バランスや快適さの合格を意味しません。
