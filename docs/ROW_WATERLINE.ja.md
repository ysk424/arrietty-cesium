# ROW の Waterline 水面

購入済みの Waterline PRO 6.5 / Gen 4 を、ROW の地理座標の水面へ接続します。
通常の `./row.ps1 "場所"` で、ローカルに準備した素材がある場合に使用します。
従来の水面へ戻す場合は `./row.ps1 "場所" -LegacyWater` を指定してください。
場所を確認する Y と、PS4・テンキーの操作は従来通りです。

## ローカル導入

UE を通常終了してから実行します。走行中には実行しないでください。

```powershell
./apps/row/tools/import_waterline.ps1 -SourceProject "D:\UnrealProjects\WaterlinePro"
```

`-SourceProject` は実際に作成した購入プロジェクトのフォルダーへ置き換えてください。
購入プロジェクトの `Content/Waterline` を ROW の Content 配下へコピーし、
`Content/Row/Waterline` に専用マテリアルを生成します。購入元は変更しません。
既にコピーがある場合は再利用し、専用マテリアルのみ再生成します。
購入元の設定・マップ・操作・プラグイン設定は取り込みません。
素材と生成物は Git 対象外です。別の環境では正規に入手した素材から再実行が必要です。
Gen 4 の内部プロパティ・関数名に依存するため、別バージョンは再確認が必要です。

## 接続範囲

- Waterline の GPU 波計算と水面の色・法線を利用します。波計算用 Actor は一つで、
  水面描画には ROW の近景・遠景メッシュを使います。
- 平均水位、地球曲率、湖面標高、岸・島のマスクと船内の切り抜きは ROW が管理します。
  波は鉛直方向に加算し、岸の位置を水平にずらしません。
- 漕ぎ方と速度に応じた航跡・白波は ROW の計算を重ねます。
- Waterline の浮力、抵抗、浅瀬シミュレーション、水中効果は無効です。
  船の移動・揺れ・入力・音は既存 ROW の処理を維持します。
- DX12 と OpenXR / Instanced Stereo の設定は維持します。製品デモの描画設定への
  置き換えは行いません。

Waterline が未導入なら従来の水面を使います。内部プロパティや動的マテリアルが
取得できない場合もログに理由を記録して従来の水面へ戻ります。
`ROW_WATERLINE_CREATED` が接続成功のログです。

## 海岸の寄せ波

海の通常起動では、描画中のCesium地形から岸を検出し、購入素材の
`MF_Shore_Gen3` に距離と方向を渡します。Waterlineの既存の波・法線・泡の
アニメーションを使います。海底を取得・推定する処理ではありません。
潮位変化や潮流も加えません。

- 岸から約24 mの帯で穏やかな寄せ波を表示します。追加の鉛直変位は最大15 cmです。
- 視点の周囲240 mは2 m間隔のメッシュを追加します。寄せ波の鉛直変位は
  200～240 mで消えます。検出範囲は周囲512 m四方、解像度512×512です。
- 検出は1秒に1回、GPU上で処理します。両眼で一つの検出結果を共有し、通常起動では
  CPUへの画像読み戻しを行いません。船・パネル・Waterlineの元の水面は検出対象外です。
- 波による船やHMDの揺れ、操船、航行可能範囲、水位は変更しません。湖では追加しません。
- OSMの取得範囲の端を海岸として使いません。地形が読み込まれた範囲で検出します。
  海岸がない場所では追加波は出ません。
- `ROW_SHORE_CAPTURE_READY` と `ROW_WATERLINE_SHORE_READY` が有効化のログです。

既にWaterlineを導入済みの別環境では、上の導入コマンドで専用素材を再生成してください。
旧素材しかない場合は海岸の追加表現を無効にし、通常のWaterline水面で起動します。
これは水深に基づく砕波計算ではなく、描画される岸に沿う視覚表現です。
地形のLOD・海岸マスクと実際の砂浜のずれまで修正する機能ではありません。

## 確認の限界

海・湖の既存水面の非 VR 描画、従来操作、海岸検出と購入素材のアニメーションを確認しました。
海岸の最終的な見た目は実走での確認が残っています。実測結果は
[VALIDATION](VALIDATION.md) に記録します。
Quest 3 / VIVE の左右の描画一致、実走中のフレーム時間、長距離移動は実機確認が必要です。
非 VR の成功を OpenXR 実機受け入れ済みとは扱いません。
水中表現や Waterline の浮力まで統合したものではありません。

追加のGPUテストは `./apps/row/tools/test_setup.ps1 -Waterline` です。
ローカル素材の準備後に実行してください。既知の岸を模したテスト画像から泡と波の時間変化まで
確認します。Cesiumの地形を取得せず、HMD・実機にも接続しません。
